# 需求文档验收检查清单

## 结构完整性

- [ ] 文件命名符合仓库约定。
- [ ] 文档类型对应的必需章节齐全。
- [ ] 标题层级与周边文档风格一致。

## 决策质量

- [ ] 状态语义明确且前后一致。
- [ ] 范围与非范围已明确分离。
- [ ] 待确认问题均为可决策、可执行问题。
- [ ] 假设与默认值已显式记录。

## 执行质量

- [ ] 实施步骤按依赖顺序排列。
- [ ] 验收标准可测试、可观察。
- [ ] 无“优化/提升”等不可验证描述。

## 一致性

- [ ] 术语在全文前后一致。
- [ ] 与模块既有文档无冲突。
- [ ] 变更记录包含日期与具体变更点。
